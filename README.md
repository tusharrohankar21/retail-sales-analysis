# Retail Sales Analysis

A beginner data analyst project analyzing retail sales data using SQL and Power BI.

## 📊 Project Overview
This project analyzes retail sales data (~51,000 orders) to uncover business insights like top-performing regions, profitable categories, and overall sales/profit trends — using SQL for data analysis and Power BI for visualization.

## 🛠️ Tools Used
- **MySQL Workbench** – Database creation, data import, and SQL queries
- **Power BI Desktop** – Interactive dashboard and data visualization

## 📁 Files in this Repository
- `retail_analysis_queries.sql` – SQL queries used for analysis (total sales, region-wise performance, category-wise profit, etc.)
- `Retail_Sales_Dashboard.pbix` – Power BI dashboard file

## 🔍 Key Insights
- Total Sales: **94K**
- Total Profit: **7.57K**
- **Office Supplies** category is the most profitable, while **Furniture** has the lowest profit margin
- Sales performance varies significantly across regions, highlighting opportunities for regional strategy improvements

## 📈 Dashboard Preview
The dashboard includes:
- KPI cards for Total Sales and Total Profit
- Region-wise Sales bar chart
- Category-wise Profit pie chart

## 🎯 What I Learned
- Setting up and querying a MySQL database
- Writing SQL queries using GROUP BY, aggregate functions, and date functions
- Connecting Power BI to a MySQL database
- Building interactive visualizations and KPI dashboards
